## Tokens

| Name | Hex | Role |
|---|---|---|
| Blueprint ink | `#0E2240` | Text, result panel |
| Chalk line | `#1D4ED8` | Links |
| Safety orange | `#F06A1D` | What to buy, dimension ticks, focus ring (dark text only on orange) |
| Form gray | `#56616B` | Secondary text |
| Plan paper | `#EEF1EF` | Page ground |
| Sheet white | `#FFFFFF` | Tool surfaces |
| WhatsApp | `#1FAF5A` | Share button, near-black text `#06210F` (white fails contrast) |

Type: Barlow Condensed 600–700 (numbers, headings) + Barlow 400–600 (body, controls).

## Principles

- Signature element: the result panel is a live blueprint with real dimension lines; everything else stays quiet.
- Short answer sentence under the H1 updates live with the inputs.
- Tool first, instant result, no Calculate button; ads only after the actions.
- Touch targets ≥ 44 px, inputs 56 px with large condensed figures, orange focus ring.
- Spanish UI copy: neutral Spanish (tú), construction terms as used in the US.

# Design Review: home-directory

Fresh-context architecture review of `proposal.md`, `design.md` and the three delta specs on branch `feat/home-directory` (2026-10-27), with measurements on a clean checkout and the existing `apps/web/dist`.

**Verdict: APPROVE WITH CHANGES.** The architecture holds (zero-JS catalog-driven home, no `packages/*` change beyond `site.ts`, typed card keys, K1 as the mechanism that makes D4 true, K9 verified in Astro 7.4.2). Five things must change before tasks: the K2 chunk arithmetic and mechanism (M-1), the notice unit and its byte cost against CP66 (M-2), the copy-fallback contradiction between K11 and CP61 (M-3), the H3 line forecast (M-4), and the missing `site-routing-i18n` delta in the proposal (M-5). None reopens D1–D8 or the owner decisions.

## Reconciliation before tasks

1. **proposal.md › Capabilities › Modified and Forecast:** add `site-routing-i18n`; H3 as three slices; PR 2 forecast and guard line (M-4, M-5).
2. **New `specs/site-routing-i18n/spec.md`:** modify "Calculator pages in the route table" (home route files, catch-all minus `home`), scenario SR23 (M-5).
3. **calculator-page delta › Terms, CP59–CP61:** define "one line" per block (answer `--text-h3 × --leading-body`; notice and copy: body line); exclude the copy fallback field; copy reserve against mounted content (M-2, M-3). **CP64:** rem-only wording independent of `min-width` syntax (m-7). **CP65:** keep only with the fixture test in H2 (m-11). **CP66:** keep; it is the gate M-2 must respect.
4. **site-shell delta:** SS25 unit and tick token (m-8); SS27/SS28 scoping-agnostic selectors and SS28 as a text search; SS29 reworded (m-9); if `inlineStylesheets: 'always'` is adopted, add it as the K2 scenario (M-1).
5. **trust-pages delta:** TP30 proved on the data module or via view props; TP32 as a test-d (m-10). TP26's `content.contract` row moves to the card keys (test edit only; the main-spec TP26 text is about the methodology and is unaffected).
6. **design.md:** Budgets table chunk rows and K2 mechanism (M-1); K10 notice variant +129 B and the trim rungs (M-2); K11 wording (M-3); Review units H3a–H3c (M-4); module map adds the CP65 fixture test and the routing delta; e2e probe with `flow-root` (m-6); dist-diff rule-set comparison (m-12).

Not provable as written: SS28 (browser-only scan), SS29 (false under K9/K10), CP61 (fallback field), TP30 (no injection point), CP65 (no fixture in the design), CP60/CP61 notice bound in answer lines (unit mismatch).
